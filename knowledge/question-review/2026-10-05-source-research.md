# 사료 빈칸·연구 예상문항 확장 검토

기준일: 2026-10-05. 원문 저장소 고정 커밋: `smart-textbooks@c27126b8b11008d96bdca159e534fbb6ec564f2b`.

## 사료탐구 빈칸

서양사·한국사·동양사 각 80개, 총 240개를 추가한다. 기존 빈칸 331개의 ID와 내용은 보존한다. 정답·승인 별칭·해설을 문항별로 작성하고 별도 AI 에이전트가 지문 전체와 함께 검토했다. 전문 역사 교원의 최종 감수를 받은 자료는 아니다. 기존 문장을 더 길게 발췌한 것만으로 새 문항을 만들거나, 단순한 연도·숫자로 개수를 채우지 않는다. 역사교육론에 같은 형식의 사료가 부족하면 수량을 억지로 맞추지 않는다.

`tools/history-questions/source-cloze-inputs/`는 작성 원본이다. 발췌문은 원문 전사의 연속된 부분이고 가장 가까운 `[사료탐구]` 표제를 추적한다. `source_cloze.py`는 정확한 인용, 정답 1회 출현, 별칭·정답 노출, 문항 중복, 근거 쪽과 기존 은행 보존을 검사한다. 전사의 정확성과 역사적 사실 판단은 문자열 검사만으로 보장하지 않으므로 문맥과 해설을 별도로 검토한다.

확인한 문제의 예:

- 서양사: 로마의 토지 제한 단위·신분 관련 의심 문장, 고등법원 수가 불명확한 구절, 빈칸만 보아 기관명이 확정되지 않는 문항을 교체했다. 수메르 법전의 귀속 및 장원 노동에 관한 부정확한 주변 설명은 완결된 사료 범위 밖으로 제외했다. 정답을 뒤에서 다시 알려 주는 문장은 사용하지 않았다.
- 한국사: 변계량의 관직을 영중추부사로 적은 전사는 1416년 해당 실록의 **경승부 윤**과 다르다. [태종실록 16년 6월 1일](https://sillok.history.go.kr/id/kca_11606001_002). 새 문항에서는 오류가 있는 관직 문장을 제외했다.
- 한국사: `응방의의소`는 해당 고려사 기록의 **음양회의소**와 다르다. [고려사 형법지](https://db.history.go.kr/id/kr_085r_0010_0010_0020_0320). 새 문항에서 해당 구절을 쓰지 않았다.
- 한국사: `권식(權直)`과 `정종 2년`은 해당 기사에서 **권직**, **정종 4년(949) 3월**이다. [고려사절요 정종](https://db.history.go.kr/id/kj_002r_0020_0050_0020). 새 문항의 발췌 범위를 조정했다.
- 동양사: 마카오 관련 원문의 **林富(임부)**·**香山澳(향산오)**가 `일부`·`랑산오`로 전사되어 정답까지 잘못될 수 있는 문항은 다른 사료로 교체했다. [마카오 문헌, 명산장](https://www.macaudata.mo/macaubook/book256/html/007001.htm).

위 전사 문제는 원문을 몰래 고치지 않고 `knownSourceIssues`에 근거·경고를 남겼다. 원문 전사와 전체 캡처의 일대일 전수 대조를 완료했다는 뜻은 아니다. 실제 비교한 범위 밖의 전사는 `transcription-unverified`를 유지한다.

## 연구 예상문항

기존 24개에서 120개(과목별 30개)로 확장한다. 신규 96개 전체의 발문·모범답안·요구조건·논문 연결을 검토했다. 공개 연구 참고 교수 27명·연구 자료 87항목은 기존 조사 범위를 유지하며, 문항을 늘렸다고 논문을 더 읽은 것으로 집계하지 않는다. [세부 작성·검증 기록](../prediction-research/expansion-review.md).

논문별 서지·초록·본문 일부의 확인 범위를 구분한다. 논문 관점의 적용·사료 평가를 연습하는 문항은 실제 시험의 사실 확인형 문제와 같다고 표시하지 않는다. 직접 연결되는 교재 발췌가 없는 서양사 4개는 무관한 교재 문장을 근거로 채우지 않고 논문 근거만 연결한다.

모든 연구 문항의 배점 합은 10점이며 모범답안과 세부 기준을 함께 제공한다. 예상도 상·중상·중에는 교육과정 및 교재 핵심과의 연결 근거와 한계를 붙인다. 이는 편집적 우선순위이지 통계적 출제 확률이 아니다. 공개 교수 목록은 실제 출제위원 명단이나 특정인의 선발 가능성 예측이 아니다.

## 학습 화면·접수

단답형 원문 모드는 작성된 근거 발췌를 문제 위에 보여 주며 정답·승인 별칭과 바로 붙은 한자·영문 풀이를 채점 전 가린다. 사료탐구 빈칸은 작성자가 확정한 지문만 표시하며 인접한 교재 설명을 자동으로 끼워 넣지 않는다. 필터 전환·문항 이동·새로고침은 기존 풀이 기록 ID를 유지한다.

이의제기는 현재 문항과 답안·채점 결과를 선택 첨부하여 Cloudflare D1에 접수한다. 서버 정식 문항과 고객 브라우저 관찰값을 분리한다. 공개 조회 API는 없으며 운영자는 기존 Cloudflare 권한으로만 접수 내용을 확인한다. [운영 안내](../../docs/APPEALS.md).

## 자동 검증 결과

- 사료 240개의 기준 정답과 승인 별칭 **624개**가 실제 로컬 채점 함수에서 모두 정답 처리되고 명백한 오답은 거절됨.
- 최종 생성물 재생성 일치 검사 통과. 기존 2,053개 연습문항의 ID와 전체 내용, 모든 원문 노트의 ID·text·html이 변경되지 않았음을 이전 커밋과 비교함.
- 문제 생성·검증 Python 테스트 39개, KB 테스트 6개 통과. KB 검증은 원문 노트 1,167개, 압축 주제 49개, 기출 발췌 310개, 일반 문항·빈칸 2,155개, 서술형 138개, 그림 연결 256개를 확인함.
- 연구 120개 출처·중복·요구조건·배점·예상도·집필 원본 재생성 검사 통과.
- 실제 브라우저에서 세 과목 사료 필터, 발췌문 범위, 채점, 마지막 문항 점프, 답안 작성 후 새로고침, 명시적 문항 링크 우선 및 모바일 너비 검증 통과.
- 기존 히스토리 브라우저 회귀 통과: 재도전, 새 탭 이어 풀기, 과목별 저장, 문항 이동, IndexedDB 재개방·수정·삭제·30일 만료, 삭제 후 늦게 도착한 채점 결과 거절.
- 단위·API 테스트 63개 및 프로덕션 빌드 통과. 이의제기는 정규화한 제출 내용으로 중복을 판정하고 문항 정정 이후 재시도에서도 기존 접수를 유지하도록 검증함. 현재 화면의 문항·시도를 링크와 관찰값에 고정하여 다른 탭의 최근 답안을 잘못 첨부하지 않음.
- 실제 브라우저에서 서로 다른 문항의 두 탭·같은 문항의 별도 재도전·정확한 시도 ID 재열기·없는 ID의 대체 금지·저장 불가 시 화면 관찰값 첨부를 확인함. 실제 로컬 Pages/D1에서 저장 실패 후 입력 유지, 같은 접수 키 재시도, HTTP 201과 접수 번호를 확인함.
