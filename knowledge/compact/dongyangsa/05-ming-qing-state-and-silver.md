# 명·청의 황제권·신사·은납

- 명 태조: 승상 폐지·육부 직속으로 황제 통제 강화. 이갑은 향촌 호구·부역 조직. [S1,S5]
- 청 군기처·주접: 황제에게 정보·명령 집중. 군기처는 독립적 합의 의회가 아니다. [S2]
- 팔기: 군사 편성과 사회적 특권 결합, 만주·몽골·한군 포함. 단순한 한족 배제가 아니다. [S2]
- 일조편법: 여러 세·역의 은납 통합. 상품 경제와 일본·아메리카 은 유입이 시행 여건. [S6]
- 지정은제: 정세를 지세에 편입. 정세 총액 고정 뒤 토지 중심 수취로 전환. [S3,S7]
- 신사: 관직 경력·학위에 기반한 향촌 지배층. 행정 보조·교육·구휼과 특권 남용의 양면. [S4]
- 주희의 격물 궁리와 왕양명의 치양지·지행합일 구분. 같은 수양론으로 처리하지 않는다. [S6]
- 공행: 광주 서양 무역 중개. 고증학의 문헌 검증과 문자옥의 사상 통제는 구분. [S8]

**구별·함정** 일조편법의 은납화와 지정은제의 과세 대상 통합은 같은 설명이 아니다.

**출제 판단** 조세의 납부 수단·부과 기준, 중앙·향촌 권력의 역할을 비교할 수 있다. 황제별 재위표·팔기 정원은 조회. 그림 불필요.

**출제 보류** 정수 고정의 기준 연도와 실제 명령 연도는 S3에서 혼동될 여지가 있어 연도 문제 보류.
