# 역사 서술형 채점 보강

확인일 2026-10-03. 박문각·윌비스·희소의 공개 해설 본문을 대조하여 자체 연습 채점에 반영했다. 공식 블로그와 유튜브도 검색했으나 원본 자막·음성이나 본문을 확인하지 못한 항목은 근거로 쓰지 않았다. 실제로 읽은 공개 학원 PDF가 채택 자료다. 원문 전체를 복제하지 않고 출처·쪽수·적용 범위만 보존한다.

## 반영한 판단

1. 문항이 요구한 대상·개수·시기·관점을 먼저 확인한다. 전쟁명과 전투명, 명칭과 설명처럼 서로 다른 요구를 섞지 않는다.
2. 서술형은 의미를 평가한다. 같은 의미의 표현은 인정하되 주체·대상·관계가 달라지는 표현은 구별한다. 용어 기입형은 사전 작성한 인정 답안만 허용한다.
3. 자료 해석형은 자료의 시점·작성자·입장과 답안의 대응을 본다. 일반 지식만 나열해도 만점을 주는 구조를 피한다.
4. 독립 기준별로 충족과 누락을 설명한다. 문항에 없던 조건을 추가하거나 한 오류 때문에 다른 정답 요소까지 지우지 않는다.

박문각 역사 분석표의 인정 답안 설명은 학원 해석이며, 윌비스의 해설과 희소의 모의문항 배점도 평가원의 확정 기준이 아니다. 현재 모든 시험에 통용되는 부분배점이나 모순 처리의 공식 규칙을 확인했다고 주장하지 않는다. 타과목 답안작성 지도는 역사교육론의 설명·적용을 설계하는 참고로만 사용한다.

## 자체 점수와 검증

`allowedScores`가 있으면 그 점수만 허용한다. 없으면 기존 정수 배점 기준에 대해 0부터 max까지의 정수를 사용한다. 이 선택은 임용의 실제 점수 단위를 추정한 것이 아니라 이 앱의 학습용 정책이다. `scoreLevels`가 있는 문항은 각 점수의 조건도 전달한다. `checkpoints`, `acceptedConcepts`, `requiredRelation`, `rejectConditions`는 문항별로 작성할 수 있다.

공통 정책의 버전을 채점 기준 버전에 결합해 오래된 기준으로 준비한 브라우저 평가가 새 기준으로 확정되지 않게 한다. API·MCP·Chrome 내장 AI가 같은 정책과 문항별 기준을 받는다. 점수 허용 범위, 실제 학생 답안 인용, 기준별 원문 인용은 서버에서 검증한다.

자동 테스트는 이 전달·검증 계약을 확인한다. 모델이 역사적 의미와 부분 충족을 얼마나 정확하게 판단하는지에 대한 실측이나 공식 점수 재현 검증은 별개이며, 이번 작업에서 유료 모델 평가나 공식 배점 검증은 수행하지 않았다.
