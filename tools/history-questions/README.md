# 교재 기반 자체 제작 문항

`curated.py`는 서양사 9개, 한국사·동양사·역사교육론 각각 8개의 선별 개념과 과목별 서술형 3문항을 담는다. 과목별 전체 단원이나 기출의 출제 범위를 대표하는 표본은 아니다. 객관식의 정답·오답 선택지와 서술형 질문은 자체 작성했으며 평가원 공식 문항으로 표시하지 않는다. 원문 빈칸은 가져온 교재 전사문 중 명료한 구절만 사용한다.

각 개념에서 객관식 1개, 용어 단답형 1개, 원문 빈칸 1개를 생성한다. 모든 개념·문항·채점 기준에는 `notes.json`의 정확한 인용과 원문 쪽 ID가 연결된다. 서술형은 3개 기준으로 10점을 배점한다. 공개 파일에는 서술형의 ID·제목·질문·쪽 ID만 넣고 채점 기준은 `functions/_data/subjects/<subject>/essays.json`에 저장한다.

새 용어 단답형은 `match: "aliases"`와 `acceptedAnswers`로 명시한 표기만 정답으로 인정한다. 예를 들어 신경제정책에 `NEP`를 허용한다. 기존 문항의 `accept` 필드와 채점 동작은 바꾸지 않으며, 원문 빈칸은 기존의 정확한 용어 채점을 유지한다.

교재 가져오기 후 표준 Python으로 실행한다.

```sh
python3 tools/history-questions/generate.py
python3 tools/history-questions/generate.py --check
python3 -m unittest discover -s tools/history-questions -p 'test_*.py'
```

생성기는 모든 과목의 원문 인용을 먼저 검증하고 나서 파일을 쓴다. 원문이 바뀌어 인용이 일치하지 않으면 자동으로 보정하거나 새 근거를 만들어내지 않고 실패한다. `--check`는 원문 검증과 재생성 결과의 일치를 검사하며 파일을 변경하지 않는다. 기존 손글씨 메모 파일은 변경하지 않는다.

전사본은 스캔 대조가 완료된 자료가 아니다. 읽을 수 없는 OCR 구절은 문항 근거로 사용하지 않았다. 예를 들어 원문에 있는 `루스벨트 당선(1933)`은 선거 연도 오류이므로 문항 인용에서 제외했다. 뉴딜의 국가 개입 및 3R에 해당하는 명료한 구절을 각각 인용했다. 가져온 전체 원문은 출처 추적을 위해 별도 KB에서 보존하며, 원문 검증 상태와 확인된 문제는 KB의 출처 정보에서 관리한다.

새 문항 추가 시 `CONCEPTS`·`ESSAYS`·`ADDITIONAL_EVIDENCE`를 함께 수정한다. 정의나 정답이 여러 사실을 포함하면 각 사실을 뒷받침할 추가 근거를 넣는다. 서술형에서 “한 가지 이상”을 요구할 경우 채점 기준과 근거도 허용 가능한 여러 답을 포함해야 한다. 인용 일치는 역사적 정확성 검증을 대신하지 않으므로 확인된 사실 오류를 답으로 채택하지 않는다.
